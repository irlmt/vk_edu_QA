# ДЗ 6. Чек лист и баг репорты

**Функционал:** Комментарии к фото

---

## Чек-лист проверки

| Проверка                           | Описание                                                      | Ожидаемый результат                                             |
|------------------------------------|---------------------------------------------------------------|-----------------------------------------------------------------|
| Добавление комментария             | Добавить текстовый комментарий из различных символов под фото | Комментарий отображается под фото                               |
| Добавление длинного комментария    | Ввести максимально допустимую длину текста                    | Комментарий сохраняется без ошибок                              |
| Пустой комментарий                 | Попытаться отправить пустое поле                              | Отображается сообщение об ошибке                                |
| Удаление комментария               | Удалить ранее добавленный комментарий                         | Комментарий исчезает                                            |
| Редактирование комментария         | Изменить уже опубликованный комментарий                       | Комментарий обновляется                                         |
| Комментарий с эмодзи               | Добавить эмодзи в комментарий                                 | Эмодзи корректно отображаются                                   |
| Комментарий из иероглифов          | Добавить комментарий с японскими иероглифами                  | Комментарий корректно отображается                              |
| Видимость для других пользователей | Проверить, видит ли другой пользователь комментарий           | Комментарий доступен другим пользователям (если фото публичное) |
